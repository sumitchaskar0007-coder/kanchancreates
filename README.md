# Shreesham Infra

A premium, responsive one-page corporate website for Shreesham Infra, built with React, Vite, Tailwind CSS v4, and Motion.

## Run locally

```bash
npm install
npm run dev
```

The site uses anchor navigation for Home, Services, Clients, About, and Contact. Replace the visual placeholder treatments in `src/index.css` with approved project imagery and update the contact details before launch.
